Image Slider
live demo link : https://hritika-24.github.io/image-slider-using-html-css-js/

This project is a simple image slider built using HTML, CSS, and JavaScript. 
It allows users to navigate through images smoothly with transition effects.

Features: 
  Navigation controls (next/previous buttons).
  
  Smooth transition effects for a better user experience.
  
  Responsive design for different screen sizes.

Technologies Used:

  HTML: Structure of the slider.
  
  CSS: Styling and animations.
  
  JavaScript: Logic for image transitions.

Installation & Usage
Clone the repository:
Open index.html in a browser.

Start navigating through images.
